3. End-to-End Request & Data Flow

Complete sequence from user interaction in React to Express authentication and PostgreSQL query execution.

sequenceDiagram
    autonumber
    actor User as User / Browser
    participant React as React App (Vite)
    participant AuthCtx as AuthContext / Axios Interceptor
    participant Express as Express REST API
    participant JWT as Auth Middleware
    participant Controller as Controller Layer
    participant DB as PostgreSQL Database

    User->>React: Enters credentials / Clicks Login
    React->>Express: POST /api/auth/login { email, password }
    Express->>Controller: authController.login()
    Controller->>DB: SELECT * FROM users WHERE email = $1
    DB-->>Controller: Return user record with bcrypt hash
    Controller->>Controller: bcrypt.compare(password, hash)
    Controller->>Express: Generate JWT signed with JWT_SECRET
    Express-->>React: Return { user, token }
    React->>AuthCtx: Store token in localStorage / Memory state
    
    Note over React, Express: Subsequent Authenticated Requests
    React->>AuthCtx: Request /api/dashboard
    AuthCtx->>Express: GET /api/dashboard (Header: Authorization: Bearer token)
    Express->>JWT: verifyToken(req.headers.authorization)
    JWT-->>Express: req.user = decodedToken
    Express->>Controller: dashboardController.getMetrics()
    Controller->>DB: Single Aggregation Query
    DB-->>Controller: { totalProjects, totalTasks, completed, pending, overdue }
    Controller-->>React: 200 OK JSON metrics
    React-->>User: Renders live animated cards & metrics
